# Badge « Ajouter à Apple Wallet »

Déposer ici le badge officiel français fourni par Apple, sous le nom exact :

    add-to-apple-wallet-fr.svg

Source : https://developer.apple.com/wallet/add-to-apple-wallet-guidelines/ (téléchargement soumis à
l'acceptation des conditions d'Apple). Ne pas modifier ni déformer le fichier.

Le fichier est détecté au build (next.config.ts). Tant qu'il est absent, la page affiche un bouton
noir « Ajouter à Apple Wallet » sans logo Apple.
